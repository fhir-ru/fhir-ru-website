# FHIR.ru — сайт российского сообщества FHIR

Новый сайт сообщества: единое оформление главной страницы и каталогов,
протоколы встреч без wiki-приложения и публикации руководств по реализации
FHIR под каноническими адресами на `https://fhir.ru`.

Репозиторий: [fhir-ru/fhir-ru-website](https://github.com/fhir-ru/fhir-ru-website).

## Границы проекта

Исходники спецификаций остаются в отдельных репозиториях:

- [RuCore и проект ГОСТ](https://github.com/fhir-ru/RuCoreIG);
- [RuAmb / RuSEMDAmbIG](https://github.com/fhir-ru/RuSEMDAmbIG).

Этот проект отвечает за сайт и интеграцию готовых публикаций IG.
Публикация исходников в GitHub не переключает действующий FHIR.ru.

Технический и визуальный ориентир — существующий проект Kostasoft;
переиспользование предполагается выборочным, без копирования всего проекта.
