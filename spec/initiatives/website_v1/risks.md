# Риски

| Риск | Как учитываем |
| --- | --- |
| Перенос старого IG под видом актуального | Повторная сверка версии, коммита и пакета перед публикацией |
| Главная IG открывается, canonical профиля не работает | Проверять реальные URL из ресурсов, HTML/JSON/XML и тип ответа |
| RuAmb использует языковой каталог | Учитывать корневой переход и `ru/`, проверять относительные ссылки |
| Более свежие протоколы остались локально | Сверять GitHub с Meetings до фиксации состава миграции |
| Несколько встреч в день или ошибочная дата | Сохранять уникальный slug и явную карту источников |
| Ссылки Zendoc потеряны при конвертации | Выделить разбор внутренних ссылок и отчёт неразрешённых переходов |
| Обновление сайта удаляет опубликованные IG | Изолировать каталоги и проверять независимые обновления |
| Копирование Kostasoft переносит лишние функции и данные | Выборочный перенос компонентов и проверка прав |
| Не определены хостинг и лицензия | Сохранить как открытые решения с задачами до реализации соответствующей части |
| Исторические обсуждения потеряны при уборке | Архивировать старые проекты отдельным этапом после инвентаризации |
