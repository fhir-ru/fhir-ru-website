# Новый сайт FHIR.ru

- ID: `website_v1`.
- Дата начала: 2026-11-25.
- Владелец продуктовых решений: Евгений Коган.

## Цель

Подготовить новый единый сайт сообщества FHIR с протоколами встреч,
каталогами и сборками IG по каноническим адресам FHIR.ru, используя
Kostasoft как ориентир реализации и оформления.

## Объём

Структура, дизайн, локальный прототип, перенос материалов, интеграция
RuCore/RuAmb, проверки и подготовка перехода с существующего сайта.
Проектирование размещения входит в инициативу; фактическое переключение
и архивирование старых репозиториев выполняются только по отдельному поручению.

Не входят: разработка профилей RuCore/RuAmb, изменение содержания ГОСТ,
восстановление всей wiki-платформы, коммерческие функции Kostasoft.
